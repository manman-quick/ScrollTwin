# ScrollTwin

ScrollTwin 是一个轻量的 macOS 菜单栏工具，用来：

- 普通滚轮鼠标（离散滚动事件）
- 触控板、Magic Mouse 等触控表面（连续滚动事件）

两类设备可以分别反转方向。普通滚轮鼠标还可以开启平滑滚动，
将一格一格的输入转换为带衰减的连续小步输出；触控板始终保留
macOS 原生滚动和惯性，不做二次平滑。

平滑滚动可分别设置“滚动距离（每一格）”和“动画响应 / 停下速度”。
“灵敏”会更快跟随输入并更快停下；“柔和”会延长动画尾部；距离设置
不改变动画时长。还可对当前前台应用单独禁用平滑。新版使用与屏幕刷新同步的临界阻尼曲线，并发送完整的
触摸与惯性阶段。监听器会定期检查运行状态，并在系统唤醒后自动恢复。

它只修改滚动事件，不改动鼠标指针、按键或系统触控手势。
设备识别会结合多指触控手势，因此可兼容 Mos 等把鼠标滚轮转换为
连续滚动事件的工具。

## 使用

1. 将 `ScrollTwin.app` 移入 `/Applications`。
2. 首次打开后，在“系统设置 → 隐私与安全性 → 辅助功能”中授权。
3. 打开 ScrollTwin 时会显示设置窗口；设置完成后直接关闭窗口即可，
   后台滚动功能仍会继续运行。
4. 以后需要设置时，从“应用程序”、访达或 Spotlight 再次打开
   ScrollTwin。

ScrollTwin 作为 `LSUIElement` 后台应用运行，不会出现在程序坞中；
菜单栏会显示 ScrollTwin 图标，可随时查看状态、开关平滑滚动或打开设置。

菜单中的“反转”是在 macOS 当前“自然滚动”设置基础上进行反转。
使用 ScrollTwin 平滑滚动时，请关闭 Mos 或其他工具中的平滑滚动，
避免同一批事件被处理两次。

“对当前应用禁用平滑”只关闭该应用中的平滑动画，不影响滚动方向。
应用排除以当前前台应用的 Bundle Identifier 保存。

例如，要实现“普通鼠标自然滚动、触控板传统滚动”：

1. 在 macOS 中关闭“自然滚动”。
2. 在 ScrollTwin 中开启“反转普通鼠标滚轮”。
3. 关闭“反转触控板 / 触控表面”。

## 本地构建

```sh
swift test
./scripts/package-app.sh
```

默认使用临时签名。如钥匙串中已有正式代码签名证书，可指定：

```sh
SCROLLTWIN_CODESIGN_IDENTITY="Developer ID Application: ..." \
    ./scripts/package-app.sh
```

应用要求 macOS 13 或更高版本。

## 浏览器滚动验证

用 Safari 或 Chrome 打开 `tools/scroll-probe.html`，滚动后页面会显示浏览器
实际渲染的帧间隔与位移数据。120Hz 显示器的理想帧间隔约为 8.33ms；
这比只统计 ScrollTwin 发出的事件次数更能反映真实手感。
